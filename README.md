# Drum Tune — настройка барабанной установки с живым тюнером (React Native / Expo)

Приложение для настройки барабанов: диаметр, количество винтов крепления
пластика — и теперь настоящий тюнер, который слушает удары через микрофон
и определяет высоту тона у каждого винта отдельно для бьющего и
резонирующего пластика. Все установки сохраняются на устройстве.

## Возможности

- Несколько барабанных установок («китов»), в каждой — любое количество барабанов
- Новая установка сразу создаётся стандартным набором: бочка, малый барабан,
  два подвесных тома (10" и 12") и напольный том (16")
- **Тип барабана** — бочка, малый, подвесной том, напольный том или другой:
  тип задаёт стартовые диаметр и число винтов, а также ориентировочный
  диапазон частот (у бочки он ниже, у малого барабана выше)
- Диаметр и количество винтов крепления пластика: быстрый выбор или своё
  значение, в том числе дробный диаметр (например `13.5`)
- **Тюнер с микрофоном**, отдельно для каждого пластика барабана:
  - **Бьющий (верхний) пластик** и **резонирующий (нижний) пластик** — два
    независимых набора измерений у одного барабана
  - **Опорный удар по центру** — задаёт ориентир (частоту в Гц), либо можно
    ввести свою цель вручную (в Гц или названием ноты, например `D2`)
  - **Удар у каждого винта** — слушается отдельно; приложение показывает
    частоту, ближайшую ноту, отклонение в центах от опорной высоты и
    подсказку — подтянуть винт или ослабить
  - Круговая схема барабана подсвечивает каждый винт по тому, насколько он
    отклоняется от цели (зелёный — близко, жёлтый — заметно, красный — сильно)
- Автосохранение всех изменений + кнопка «Сохранить установку» с подтверждением

## Типы барабанов и ориентиры по частоте

Тип барабана задаётся при добавлении и меняется в настройках барабана. Из типа
берутся стартовые диаметр и количество винтов, а частота-ориентир считается
по формуле «константа типа / диаметр», поэтому при уточнении диаметра
рекомендация пересчитывается сама.

| Тип | Стартовый размер | Ориентир (22"/14"/12"/16") |
| --- | --- | --- |
| Бочка | 22", 8 винтов | ≈ 59–73 Гц |
| Малый барабан | 14", 10 винтов | ≈ 251–307 Гц |
| Подвесной том | 12", 6 винтов | ≈ 240–293 Гц (для 10" — 288–352 Гц) |
| Напольный том | 16", 8 винтов | ≈ 135–165 Гц |
| Другой барабан | 14", 8 винтов | без рекомендации |

Это приблизительные ориентиры для частоты у винта (то, что слышит тюнер):
реальный тон зависит от пластика, глубины обечайки и манеры игры. Диапазон
поиска высоты тона в тюнере тоже сужается под тип барабана, чтобы на шумном
ударе не уехать на октаву.

## Как пользоваться тюнером

1. Откройте барабан → «Бьющий пластик» или «Резонирующий пластик»
2. Нажмите «Удар» у строки «Центр» и один раз чётко ударьте по пластику —
   это опорная высота
3. По очереди нажимайте «Удар» у каждого винта и бейте пластик в точке
   примерно в 2–3 см от обода, напротив этого винта (стандартная техника
   настройки барабанов)
4. Подкручивайте винт в указанную сторону (▲ подтянуть / ▼ ослабить), пока
   отклонение не станет близким к нулю, и переслушивайте заново
5. То же самое можно повторить для второго пластика этого барабана

Пока цель не задана вручную и нет опорного удара по центру, тюнер сравнивает
измерения с ориентиром для типа барабана. Своя цель (в Гц или нотой) всегда
важнее, а кнопка «Сбросить цель» возвращает к автоматическому ориентиру.

Для записи приложению нужен доступ к микрофону — система запросит
разрешение при первом ударе.

> Тюнер с микрофоном работает в собранном приложении на iOS/Android (через
> Expo Go или сборку). В веб-версии (`expo start --web`) запись звука не
> поддерживается — экран тюнера покажет соответствующее сообщение.

## Как работает определение высоты тона

Коротко: приложение слушает микрофон потоком сырых PCM-сэмплов ~1.8 секунды,
находит момент самого громкого всплеска (удар), берёт отрезок сразу после него
(когда начальный щелчок уже стих, а резонанс ещё звучит) и ищет в нём основной
тон нормированной автокорреляцией, которая учитывает энергию перекрывающихся
окон и потому не смещает результат к высоким частотам. Диапазон поиска —
примерно 30–500 Гц в зависимости от типа и размера барабана, что покрывает
большинство барабанов от бас-бочки до маленьких томов; под каждый тип
барабана он дополнительно сужается. Если тон не удалось
уверенно определить (тихий или нечёткий удар, посторонний шум), приложение
честно сообщает об этом и предлагает ударить ещё раз — подробности в
`src/audio/pitchDetect.js`.

## Структура проекта

```
drum-tune/
├── App.js                      # точка входа Expo
├── app.json / babel.config.js
├── package.json
└── src/
    ├── App.js                  # состояние, навигация между экранами
    ├── model.js                 # модель барабана: тип, два пластика, измерения
    ├── drumTypes.js             # типы барабанов и ориентиры по частоте
    ├── theme.js                 # цвета и отступы
    ├── constants.js             # пресеты диаметра и количества винтов
    ├── storage.js                # сохранение в AsyncStorage
    ├── utils.js
    ├── audio/
    │   ├── recorder.js          # поток PCM с микрофона, запуск анализа
    │   ├── pitchDetect.js        # поиск высоты тона (автокорреляция)
    │   └── notes.js              # частота ↔ нота, расчёт центов
    ├── components/
    │   └── DrumVisualizer.js     # круговая схема барабана (SVG)
    └── screens/
        ├── KitListScreen.js      # список установок
        ├── KitEditorScreen.js    # барабаны внутри установки
        ├── DrumEditorScreen.js   # тип, диаметр, винты, вход в тюнер
        └── TunerScreen.js        # сам тюнер — слушает удары
```

## Запуск

Понадобится Node.js и Expo CLI (`npx` достаточно, установка не нужна).

1. Перейдите в папку проекта:
   ```bash
   cd drum-tune
   ```
2. Установите зависимости — лучше через `expo install`, чтобы версии точно
   подошли под установленный у вас Expo SDK:
   ```bash
   npm install
   npx expo install expo-audio @react-native-async-storage/async-storage react-native-svg
   ```
3. Запустите проект:
   ```bash
   npx expo start
   ```
4. Откройте в Expo Go на телефоне (отсканировав QR-код) или запустите
   симулятор iOS/Android клавишами `i` / `a` в терминале. Для настоящего
   теста тюнера нужен физический телефон рядом с барабаном — симулятор
   микрофон обычно не передаёт.

Если начинаете с нуля — создайте пустой проект `npx create-expo-app drum-tune`,
а затем перенесите в него файлы `src/`, `App.js` и `app.json` из этого архива.
